# Survey Form _(survey-form)_

A small HTML/CSS coursework exercise for building an accessible bug-report survey form.

## Background

This is an early front-end exercise focused on semantic form controls, validation attributes, radio groups, checkboxes, and basic responsive styling.

## Install

```bash
git clone https://github.com/ameliaeckard/survey-form.git
cd survey-form
python -m http.server 8000
```

## Usage

Open `http://localhost:8000/main.html` to view the form.
